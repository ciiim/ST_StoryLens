# 剧情镜头

一个免编译安装的 SillyTavern UI 扩展。它先根据角色卡与故事书创建可编辑的生图提示词素材库，再在每次角色回复后调用文本模型，从素材库中选择最符合当前剧情的场景和角色形象，并显示在聊天侧边栏。

## 当前功能

- 读取当前角色卡、角色卡内嵌故事书，以及用户勾选的外部 World Info。
- 自定义场景与角色动态数量，一次生成对应数量的提示词。
- 场景覆盖日常/非日常；角色动态覆盖外貌、身材、服装、表情和动作。
- 提示词可修改、复制、单项重新生成，也可新增或删除槽位。
- 用户在任意生图工具完成图片后，将图片拖入对应槽位。
- 不要求全部上传完成即可进入实时模式；未上传槽位会显示明确的空状态。
- 每次角色消息渲染完成后自动分析最新回复，并匹配场景与角色动态。
- 支持手动切换、重新分析，以及分别锁定场景或形象。
- 支持酒馆当前预设 API，或浏览器直连 OpenAI Chat Completions 兼容接口。

## 安装

将本仓库放入 SillyTavern 的第三方扩展目录，或将仓库发布到 Git 后，在酒馆的“扩展 → 安装扩展”中填写仓库 URL：

```text
SillyTavern/data/<用户>/extensions/story-lens
```

重载酒馆后，在扩展设置中找到“剧情镜头”，点击“打开素材工作台”。

## 使用流程

1. 打开一个角色聊天。
2. 在素材工作台中选择要读取的故事书，填写场景和角色动态数量。
3. 选择酒馆当前预设，或在“API与分析”中配置自定义接口。
4. 点击“分析设定并生成提示词”。
5. 复制每条提示词到自己的生图工具，随后把图片上传回对应槽位。
6. 点击“进入实时模式”。图片可以稍后继续补齐。

## 数据与安全

- 图片和素材库保存在当前浏览器的 IndexedDB（`localforage`）中，不会写进角色卡或故事书。
- 每个角色使用独立素材库；聊天中的当前匹配结果存放在聊天 metadata。
- 自定义 API 地址和模型名会保存在扩展设置中。
- API Key **只保存在当前页面内存中**，不会写入扩展设置。刷新页面后需重新输入。
- 自定义接口由浏览器直接访问，因此服务必须允许当前酒馆地址进行 CORS 请求。需要隐藏密钥或绕过 CORS 时，应另配受信任的服务端代理/Server Plugin。

## 兼容性说明

- 目标版本：SillyTavern 1.12.12 及以上。
- 当前版本优先支持单角色聊天。群聊会使用独立素材库，但不会自动合并所有群成员的完整角色设定。
- 模型的 Structured Output 支持因 API 而异；插件也包含从普通 JSON 文本中提取结果的兼容逻辑。
- 首次生成会替换当前角色已有的素材槽位与图片，界面会在操作前二次确认。

## 文件结构

```text
manifest.json       酒馆扩展清单
index.js            初始化与消息事件监听
src/context.js      角色卡和故事书读取
src/generation.js   提示词生成与剧情匹配
src/storage.js      IndexedDB 素材存储
src/ui.js           素材工作台和实时侧栏
style.css           响应式视觉样式
design/             界面概念图
```
